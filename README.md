# alejandrodavidmartino.github.io

Mi portfolio personal: **https://alejandrodavidmartino.github.io**

Está hecho a mano con HTML, CSS y JavaScript, sin frameworks ni herramientas de compilación. GitHub Pages publica los archivos tal cual.

## Estructura

- `index.html`: el contenido de la página.
- `styles.css`: el diseño, con modo claro y oscuro y adaptado a móvil.
- `script.js`: el cambio de tema, el menú en móvil y las animaciones al hacer scroll.
- `assets/`: el CV en PDF y el favicon.

## Ver en local

Basta con abrir `index.html` en el navegador.
